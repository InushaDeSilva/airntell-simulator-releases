# Airntell Flight Simulator

Download tester builds from [Releases](https://github.com/InushaDeSilva/airntell-simulator-releases/releases). This repository holds downloads; the Unity source is private.

The current public release, `v0.1.12`, has Windows x64 and ARM64 packages. Check each release's notes for its tested platforms and known issues. macOS and Linux downloads will appear only after those builds have been tested.

For `v0.1.12`, download the launcher ZIP for your Windows architecture, extract it, and run `AirntellFlightSimulatorLauncher.exe`. Use **Download and install** to fetch the simulator. Keep the launcher files together. You can start an installed version offline.

Updates are optional. The current launcher checks GitHub Releases and installs after you close the simulator. A future version will move update controls into the game; the `v0.1.12` launcher does not update itself.

The simulator is a local open-pit mine preview. It is not connected to a real aircraft. Packages are unsigned unless a release explicitly says otherwise.
